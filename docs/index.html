Features

⚡
Live refresh
CPU & GPU temps update every 2 seconds in real-time
📊
Min / Max
Tracks lowest and highest temperatures during the session
🎨
Color-coded
Green for safe, yellow for warm, red for hot thresholds
🌡️
°C / °F toggle
Click the unit button to switch between Celsius and Fahrenheit
🔑
Self-elevating
One UAC prompt grants access to accurate CPU readings
📦
Zero setup
Auto-installs dependencies — just double-click and go
