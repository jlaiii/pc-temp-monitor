PC Temperature Monitor

Real-time CPU & GPU temperature tracker for Windows

Download View on GitHub

Screenshot coming soon — run the app to see it live

Features

  • Live refresh — temps update every 2 seconds
  • Min / Max — tracks lowest and highest temps
  • Color-coded — green, yellow, red thresholds
  • °C / °F toggle — click to switch units
  • Self-elevating — one UAC prompt for accurate temps
  • Zero setup — auto-installs dependencies

Quick Start

python temp_monitor.py

Or double-click the file in Explorer. Accept the UAC prompt when it appears.

How It Works

Requirements

Windows 10+, Python 3.8+, NVIDIA GPU. Internet on first run for dependency installs.
